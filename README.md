# Azure Cloud & DevOps Portfolio

## Publish for free with GitHub Pages
1. Download and unzip this package.
2. Add your own PDF resume to this folder and name it exactly `resume.pdf`.
3. Edit `index.html` to replace the email, LinkedIn URL, job titles, employment dates and project links. Verify every claim before publishing.
4. Open your public repository: https://github.com/Bkumarsh/babloo-devops-portfolio
5. Select **Add file → Upload files**, then upload `index.html`, `styles.css`, `script.js`, `README.md`, and `resume.pdf`.
6. Commit the files.
7. Go to **Settings → Pages**. Under Build and deployment select **Deploy from a branch**, branch `main`, folder `/(root)`, then Save.
8. After GitHub finishes deployment, open `https://bkumarsh.github.io/babloo-devops-portfolio/`.

If your repository has a different name, the URL will be different. GitHub Pages can take a few minutes to publish.

## Important before going public
- This package does not contain a resume because your real PDF has not been provided.
- Replace the placeholder email and LinkedIn URL.
- Confirm titles, dates and responsibilities for Nokia, TCS, Capgemini, Mindtree and Decon. The page deliberately does not invent them.
- The project summaries are starter descriptions based on technologies discussed; verify them against actual code and replace GitHub profile links with direct repositories when available.
- Do not publish confidential employer information, credentials, customer data or private architecture.
- To update the site later, edit the files on GitHub and commit the changes. Replace `resume.pdf` when you update your resume.
